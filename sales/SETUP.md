# Buyer Setup

1. Install Python 3.12+.
2. Copy `agent/profile.example.json` to the ignored `agent/profile.json`.
3. Replace placeholders with verified professional information only.
4. Review `agent/config.json` and set minimum rates and keywords.
5. Connect the buyer's authorized Upwork account through the supported integration.
6. Run preview mode first.
7. Review Connects cost, qualification gaps, screening answers, and proposal draft.
8. Submit only after explicit user confirmation.

## Privacy
`agent/profile.json` and runtime job data are ignored by Git. Never commit tokens, cookies, credentials, or private profile data.

## Operational rule
The product prepares applications; it does not independently spend Connects. Final submission requires explicit confirmation at the time of submission.
